# المُعين في كتاب الإيمان — شرح النووي وتعليقات الشيخ ياسر برهامي

موسوعة تفاعلية شاملة لدراسة **كتاب الإيمان من صحيح مسلم** بشرح الإمام النووي وتعليقات واستدراكات فضيلة الشيخ ياسر برهامي، مع:

- **فهرس الكتاب** وتتبع التقدّم في القراءة.
- **قارئ الكتاب المطابق للنسخة المصوّرة** (٣٠٩ صفحات) مع البحث النصي الفوري ومطابقة صفحات الـ PDF.
- **وضع الدراسة التحليلي** مع فصل المتن عن الحاشية والتمييز اللوني لأنماط العلم.
- **التشجيرات العلمية والملخصات** لكل باب.
- **بنك الأسئلة والاختبار الشامل** مع حفظ التقدم والأسئلة المحفوظة والأخطاء محلياً.

---

## التشغيل محلياً (Local Development)

**المتطلبات:** Node.js (يفضل الإصدار 20 أو أحدث)

```bash
npm install
npm run dev
```

للتحقق من الأنواع البرمجية والاختبارات وبناء النسخة النهائية:

```bash
npm run lint
npm test
npm run build
```

---

## النشر عبر GitHub Pages

المشروع مهيّأ للنشر التلقائي على **GitHub Pages** عبر ملف `.github/workflows/deploy.yml`:

1. ارفع المشروع إلى مستودع على GitHub على فرع `main`.
2. من إعدادات المستودع افتح **Settings → Pages**.
3. تحت **Build and deployment → Source** اختر **GitHub Actions**.
4. سيعمل الـ Workflow تلقائياً (`Deploy to GitHub Pages`) ويبني المشروع وينشره على رابط `https://<username>.github.io/<repo-name>/`.
